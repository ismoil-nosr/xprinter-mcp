# Open Xprinter MCP

[English](../README.md) · **Русский** · [简体中文](README.zh-CN.md)

MCP-сервер для AI: подготовка этикеток, превью, печать и проверка своих заданий на **Xprinter XP-330B**. Клиенты Windows, Linux и macOS используют одинаковый API. Принтер подключён по USB к Mac, на котором работает сервер. Прямое USB-подключение сервера к Windows/Linux в этой версии ещё не реализовано.

## Установка на Mac с принтером

1. Установите [Open Xprinter 0.3.0+](https://github.com/ismoil-nosr/xprinter-macos/releases/latest), настройте очередь `XP330B_OpenSource` и проверьте одну этикетку в обычном приложении. Установщик пока без подписи Apple; следуйте его инструкции установки.
2. Установите [Node.js 24 LTS или новее](https://nodejs.org/en/download). Обычный драйвер и приложение Node не требуют.
3. Скачайте `.tgz` и `SHA256SUMS.txt` из [релиза MCP](https://github.com/ismoil-nosr/xprinter-mcp/releases/latest). Проверьте SHA-256 архива, затем:

```sh
npm install --global ./ismoil-nosr-xprinter-mcp-0.1.0.tgz
xprinter-mcp doctor
```

Проверка `doctor` не расходует бумагу: она проверяет очередь и генератор. Готовность CUPS не доказывает физическое наличие USB-принтера. npm загружает зависимости, зафиксированные в архиве; пакет пока распространяется через GitHub Releases, а не npm registry.

## Подключение локально

В настройках MCP вашего AI-клиента используйте абсолютные пути к Node и установленному модулю:

```json
{
  "mcpServers": {
    "xprinter": {
      "command": "/absolute/path/to/node",
      "args": ["/absolute/path/to/xprinter-mcp/dist/cli.js", "stdio"],
      "env": {"XPRINTER_LANGUAGE": "ru", "XPRINTER_ALLOW_PRINT": "1"}
    }
  }
}
```

Путь к Node можно узнать командой `command -v node`. Формат внешнего блока настроек зависит от AI-клиента. При глобальной установке можно использовать абсолютный путь `command -v xprinter-mcp` с аргументом `stdio`, если PATH клиента также содержит Node. [Примеры](../examples).

Печать по умолчанию выключена. `XPRINTER_ALLOW_PRINT=1` разрешает расход бумаги; предоставляйте это право только доверенным клиентам и настройте подтверждение инструментов в самом AI-клиенте. Поле `confirmed: true` помогает избежать случайной печати, но само по себе не доказывает согласие человека. Без этого флага окружения можно готовить этикетки и смотреть превью.

Команда `xprinter-mcp config` выводит готовый JSON с настоящими абсолютными путями. По умолчанию печать в нём выключена; скопируйте настройки в свой AI-клиент и включите её при необходимости.

## Печать

1. AI читает `printer_capabilities` и `printer_status`.
2. Уточняет реальный размер и материал рулона. Ширина — поперёк печатающей головки, высота — вдоль подачи; зазор измеряется отдельно. Начальный профиль: 58×40 мм, зазор 2 мм, плотность 7.
3. `prepare_labels` создаёт Code 128, QR или текст; `prepare_pdf` принимает PDF в base64. Возвращаются ID, число страниц и PNG **только первой страницы**. Бумага не движется.
4. Пользователь проверяет превью, содержимое партии и явно поручает печать. `print_labels` получает `confirmed: true` и новый UUID `idempotencyKey` для этой намеренной печати.
5. При повторе сетевого запроса AI сохраняет тот же UUID и параметры. Если результат `uncertain`, нужно проверить очередь на Mac и бумагу; автоматически отправлять ещё одну печать с новым ключом нельзя.

`quantity` в записи создаёт страницы, `copies` повторяет весь документ. Ограничение считается как страницы × копии. Начальные пределы — 100 этикеток на задание и 500 за час на весь принтер через общее хранилище MCP. Отменённые и неизвестные задания тоже учитываются, чтобы не занижать расход.

`preview_label` показывает вашу подготовленную этикетку. `job_status` проверяет только ваше задание, а `cancel_job` отменяет только ваше незавершённое задание после проверки его идентичности в CUPS. Уже напечатанное отменить невозможно. Статус «завершено» в CUPS не подтверждает ровную печать или читаемость штрихкода.

## Подключение с Windows/Linux и через интернет

Удалённому клиенту не нужен Mac-драйвер. Для приватного доступа используйте SSH с ключом, например [ssh.json](../examples/ssh.json). На клиенте нужен SSH, на серверном Mac — Node, драйвер и доступ к очереди. Все клиенты одного SSH/Mac-аккаунта разделяют его локальную идентичность.

Для публичного HTTPS нужны домен, TLS-прокси и внешний OAuth-провайдер с JWT access tokens. Сам HTTP-сервер слушает только `127.0.0.1`; анонимного HTTP нет. [Подробная инструкция](REMOTE.md) и [требования OAuth](OAUTH.md). Провайдер выдаёт права `xprinter.read`, `xprinter.prepare`, `xprinter.print`, `xprinter.cancel`; издатель, аудитория, подпись и срок токена проверяются. Устанавливать драйвер на удалённый Windows/Linux не требуется.

Поддерживаются MCP 2026-07-28 и совместимый режим клиентов 2025 года через официальный SDK v2. Старый отдельный транспорт HTTP+SSE не предоставляется. Интерфейс инструментов доступен на английском, русском и упрощённом китайском; имена инструментов и JSON-поля неизменны. Code 128 принимает ASCII, QR — Unicode.

## Данные, ограничения и разработка

Подготовленные PDF/PNG приватны для вашей идентичности и доступны 15 минут. Общее хранилище ограничено 64 МиБ/128 объектами. Квитанции повторов хранятся 30 дней. Удаление базы также удаляет защиту от повтора; сначала проверьте незавершённые/неизвестные задания. SQLite использует встроенный API Node; предупреждение об экспериментальном SQLite на stderr в Node 24 не портит MCP.

MCP ограничивает ширину 20–76 мм, длину подачи 10–200 мм, партию 50 записями/100 страницами. PDF: до 2 МиБ и 100 страниц; результат до 6 МиБ. Превью только первой страницы. Произвольные пути, ссылки, shell, сырые TSPL-команды, калибровка и администрирование не являются MCP-инструментами. Разбор PDF ограничен по объёму и времени, но не помещён в отдельную системную песочницу; предоставляйте доступ доверенным людям.

```sh
git clone https://github.com/ismoil-nosr/xprinter-mcp.git
cd xprinter-mcp
npm ci --ignore-scripts
npm test
npm pack
```

Для проверки настоящего генератора задайте `XPRINTER_RENDERER` — абсолютный путь к executable внутри Open Xprinter 0.3.0+. Тесты не печатают бумагу. В CI ядро проверяется на Windows/Linux/macOS, генератор — на Mac ARM и Intel. [Результаты и границы проверки](VALIDATION.md).

Удаление: остановите клиенты/службу и выполните `npm uninstall --global @ismoil-nosr/xprinter-mcp`, затем удалите настройки MCP из клиента. Драйвер и приватная база сохраняются. Не храните базу на сетевом диске. Другие приложения Mac печатают вне ограничений MCP.

Два репозитория выпускаются независимо: [xprinter-macos](https://github.com/ismoil-nosr/xprinter-macos) — драйвер/приложение/генератор, этот — протокол/права/клиентские инструкции. Будущие Windows/Linux USB-бэкенды можно добавить сюда без изменения общего API. [Архитектура](ARCHITECTURE.md), [вклад в проект](../CONTRIBUTING.md), [безопасность](../SECURITY.md).
